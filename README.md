Weather Application

A simple and responsive Weather Application built using HTML, CSS, and JavaScript. It uses a weather API to fetch real-time weather information based on a city name entered by the user.

Features

Search by City: Get weather information by entering any supported city name.

Real-Time Weather Data: Fetches current weather details from an external weather API.

API Integration: Uses JavaScript's Fetch API to send HTTP requests and retrieve weather data.

Asynchronous JavaScript: Handles API requests using asynchronous operations.

Dynamic UI: Displays weather information dynamically based on the API response.

Error Handling: Handles invalid city names and API request errors.

Responsive Design: Built with CSS to provide a user-friendly interface across different screen sizes.

Technologies Used

HTML5 — Structures the application.

CSS3 — Styles the interface and provides responsive layouts.

JavaScript (ES6+) — Handles application logic, API requests, and dynamic content updates.

Weather API — Provides real-time weather information.

Fetch API — Retrieves weather data from the API using HTTP requests.

Async/Await — Simplifies handling asynchronous API calls.
